## 3MF Library

3MF Library is open source under the [MIT licence](https://github.com/jurjen74/3mf-library/blob/main/LICENSE),
© Jurjen Ladenius.

## Built with

- [ASP.NET Core](https://dot.net) and [SQLite](https://sqlite.org) (Microsoft.Data.Sqlite, MIT)
- [Dapper](https://github.com/DapperLib/Dapper) (Apache 2.0)
- [HtmlSanitizer](https://github.com/mganss/HtmlSanitizer) (MIT)
- [three.js](https://threejs.org) for the 3D viewer (MIT)
- [Inter](https://rsms.me/inter/) by Rasmus Andersson (SIL Open Font License 1.1)
- This site: [Astro Starlight](https://starlight.astro.build) (MIT)

The "Open in your slicer" link formats were checked against the slicers' own source code and
[Manyfold](https://github.com/manyfold3d/manyfold)'s handlers. Manyfold is a larger, different take on organising 3D
models and well worth a look.

The login page backgrounds were generated with [Magnific](https://magnific.ai) and aren't covered by the MIT licence.
